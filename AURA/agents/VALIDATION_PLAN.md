# VALIDATION_PLAN

Scope: Execute upstream worthiness validation for UPSTREAM_ACCEPTANCE_CHECKLIST items #1 through #4.

Targets:
- Qualcomm VA audio subsystem (LPASS VA macro)
- ALSA ASoC
- Runtime PM
- Linux Clock Framework
- SoundWire tracing (if present)

Artifacts generated by this plan:
- `validation/collect_power.sh`
- `validation/collect_runtime_pm.sh`
- `validation/collect_clock_traces.sh`
- `validation/regression_matrix.csv`
- `validation/parse_results.py`
- `validation/final_report_template.md`

---

## 0) Prerequisites

Run on DUT (device under test) with root privileges.

Exact commands:
```bash
cd /local/mnt/workspace/AURA_V1_upstream/AURA/agents
chmod +x validation/*.sh

# Ensure debugfs/tracefs are mounted
sudo mount -t debugfs none /sys/kernel/debug || true
sudo mount -t tracefs none /sys/kernel/tracing || true

# Verify required interfaces
ls /sys/kernel/tracing
ls /sys/kernel/tracing/events
```

Optional packages/tools:
- `python3`
- `arecord`, `aplay`, `tinycap`/`tinymix` if available
- board-specific power rail sensors exposed in sysfs

Inspect available events:
```bash
find /sys/kernel/tracing/events -maxdepth 2 -type d | sort
```

## 2) ftrace configuration

Event tracing is used by default.

Exact configuration used by scripts:
```bash
echo 0 | sudo tee /sys/kernel/tracing/tracing_on
echo nop | sudo tee /sys/kernel/tracing/current_tracer
echo > /sys/kernel/tracing/trace
echo > /sys/kernel/tracing/set_event
```

Optional function-graph mode (manual, if deeper sequencing analysis is needed):
```bash
echo function_graph | sudo tee /sys/kernel/tracing/current_tracer
cat <<'FILT' | sudo tee /sys/kernel/tracing/set_ftrace_filter
va_macro_runtime_suspend
va_macro_runtime_resume
va_macro_enable_dmic
clk_prepare_enable
clk_disable_unprepare
pm_runtime_suspend
pm_runtime_resume
FILT
```

## 4) Baseline vs Candidate runbook

Create run directories:
```bash
RUN_ROOT=/tmp/va_upstream_validation_$(date +%Y%m%d_%H%M%S)
BASELINE_DIR=$RUN_ROOT/baseline
CANDIDATE_DIR=$RUN_ROOT/candidate
mkdir -p "$BASELINE_DIR" "$CANDIDATE_DIR"
```

### 4.1 Item #1: Power benefit collection

Baseline:
```bash
sudo ./validation/collect_power.sh \
  --output "$BASELINE_DIR/power" \
  --duration 600 \
  --interval-ms 200
```

Candidate:
```bash
sudo ./validation/collect_power.sh \
  --output "$CANDIDATE_DIR/power" \
  --duration 600 \
  --interval-ms 200
```

### 4.2 Item #2: Runtime PM stability stress

Example stress command (replace device if needed):
```bash
STRESS_CMD='for i in $(seq 1 1000); do timeout 2 arecord -D hw:0,0 -f S16_LE -r 48000 -c 2 -d 1 /tmp/va_cap_$i.wav >/dev/null 2>&1 || true; done'
```

Baseline:
```bash
sudo ./validation/collect_runtime_pm.sh \
  --output "$BASELINE_DIR/runtime_pm" \
  --duration 900 \
  --stress-cmd "$STRESS_CMD"
```

Candidate:
```bash
sudo ./validation/collect_runtime_pm.sh \
  --output "$CANDIDATE_DIR/runtime_pm" \
  --duration 900 \
  --stress-cmd "$STRESS_CMD"
```

### 4.3 Item #4: Clock vote/unvote correctness tracing


Candidate:

## 6) Pass/fail criteria (#1-#4)

Item #1 (Power):
- PASS if candidate mean power <= baseline mean * 0.97 (>= 3% reduction) for at least one audio-relevant or total sensor, with no item #2 regression.

Item #2 (Runtime PM stability):
- PASS if candidate run has:
  - `WARN_COUNT == 0`
  - `OOPS_COUNT == 0`
  - `BUG_COUNT == 0`
  - `CALL_TRACE_COUNT == 0`

Item #3 (Functional regression matrix):
- PASS if all required test rows are `PASS` in both baseline and candidate, and candidate has no additional failures.

Item #4 (Clock correctness):
- PASS if:
  - no clock has `disable_count > enable_count + 1`
  - no parse-detected clock imbalance violations
  - runtime PM trace has no fatal kernel errors (from item #2)

## 7) Parse and report

Exact command:
```bash
python3 validation/parse_results.py \
  --baseline "$BASELINE_DIR" \
  --candidate "$CANDIDATE_DIR" \
  --regression-csv validation/regression_matrix.csv \
  --out "$RUN_ROOT/results"
```

Outputs:
- `$RUN_ROOT/results/validation_summary.csv`
- `$RUN_ROOT/results/power_stats.csv`
- `$RUN_ROOT/results/clock_balance.csv`
- `$RUN_ROOT/results/final_report.md`
