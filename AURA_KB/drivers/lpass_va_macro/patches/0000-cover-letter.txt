Subject: [RFC PATCH 0/7] ASoC: codecs: lpass-va-macro: upstream alignment series

This RFC series contains the current generated downstream-to-upstream
alignment work for the Qualcomm LPASS VA macro codec driver.

The goal is to move the downstream lpass-cdc VA macro implementation toward
the existing upstream lpass-va-macro architecture instead of upstreaming the
vendor lpass-cdc, msm-cdc-pinctrl, swr-wcd, and lpass-cdc-clk-rsc frameworks.

The series is marked RFC because validation so far is static only. It has not
been compile-tested in a complete kernel tree and has not been validated on
Qualcomm audio hardware with runtime PM, clock, DAPM, or SoundWire tracing.

Patch summary:
  1. ASoC: codecs: lpass-va-macro: isolate register-name migration
  2. ASoC: codecs: lpass-va-macro: drop downstream pinctrl and version paths
  3. ASoC: codecs: lpass-va-macro: remove vendor SoundWire notification coupling
  4. ASoC: codecs: lpass-va-macro: remove lpass-cdc macro framework dependency
  5. ASoC: codecs: lpass-macro-common: add shared helper infrastructure with VA consumer
  6. ASoC: codecs: lpass-va-macro: migrate runtime PM and clock sequencing
  7. ASoC: codecs: lpass-va-macro: remove residual downstream symbols

Known pre-submission issues from the quality gate:
  - The 7-patch chain applies in submission order and has no trailing whitespace findings.
  - checkpatch still reports non-whitespace warnings/checks that need style cleanup.
  - The downstream compatible string qcom,lpass-cdc-va-macro is deferred because changing DT ABI requires SoC/board evidence.
  - Runtime PM and clock sequencing needs hardware or trace evidence.

Testing performed:
  - Static patch generation and JSON validation for each patch artifact.
  - Full 7-patch apply validation in submission order.
  - Grep audit for removed vendor framework symbols after full-series application.
  - checkpatch --strict whitespace audit across all seven patches.

Testing not yet performed:
  - Full kernel build.
  - dt_binding_check or dtbs_check, since no DT binding patch is currently required.
  - Runtime PM, clock framework, DAPM, SoundWire, or audio capture validation on hardware.
