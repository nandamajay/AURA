# RB3 Failure Reasoning

## Failure dimensions
- overlay mismatch
- unresolved routes
- missing mixer dependencies
- unsupported backend activity
- SoundWire dependency failure
- playback not completed

## Rule
Each failure reason must be backed by explicit evidence gaps or telemetry mismatch.
Unknown evidence is preserved as advisory uncertainty instead of inferred success.

## Output posture
- advisory-only
- no parity/equivalence/merge claims
